Multimodal Document Intelligence is a tool where you upload a PDF and ask it questions in plain English. It can answer using the text, tables, and even charts or images in the document, not just the written text.

Here's how it works: the PDF gets broken into pieces. Text is split into chunks, tables are pulled out as structured data, and charts or images are described in words using an AI vision model. All of these pieces are turned into number-based representations (embeddings) and stored together, so they can all be searched the same way. When you ask a question, the system finds the most relevant pieces, sends them to an AI model to generate an answer, and shows you exactly which page and part of the document the answer came from.
